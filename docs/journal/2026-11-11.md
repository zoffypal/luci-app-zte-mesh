# 2026-11-11

## 19.07 的 ipk：在 QWRT 4.4.60 上跑起来了

京东云 AX1800 Pro（QWRT R24.5.1，实为 OpenWrt 19.07-SNAPSHOT，内核
4.4.60）装 0.1.0-28 那一轮卡在两处：`ns-run` 的 `close_range()` 在
4.4 上回 ENOSYS，19.07 的 LuCI 不读 JS 页面。修完这两处再装，卡在
第三处：私有 `libc.so.6` 是 Buildroot glibc 2.26，最低内核标 5.4.0，
加载器 `--list` 直接 `FATAL: kernel too old`，退出码 127。

查 glibc 源码 `sysdeps/unix/sysv/linux/dl-osinfo.h` 确认：加载器只拿
自己的编译期 `__LINUX_KERNEL_VERSION`（即 `--enable-kernel` 的值）
跟运行内核比，**不检查主程序的 ABI tag**——所以 `multiapd` 自带的
5.4.0 tag 不构成阻塞，不动它；也不能只改 tag 充数。原厂 ELF 按真实
ABI 核对是软浮点（`e_flags 0x5000200`，无 `Tag_ABI_VFP_args`，
INTERP `/lib/ld-linux.so.3`），工具链用 arm-linux-gnueabi，不是
gnueabihf。

做法：同一版 glibc 快照（Buildroot 2018.02.12 的 `glibc-2.26-193`）
按 `--enable-kernel=4.4.0` 重编，成套换掉五个库；`ns-run` 在 ENOSYS
时逐个关 fd，再加 `uname()` 预判、低于 5.9 根本不发起 `close_range`
（第二版日志里仍有的 syscall 436 记录就此消失）；LuCI 控制器
`index()` 内现取 `translate`（旧 LuCI 把 `index()` 序列化进
`/tmp/luci-indexcache` 后文件级 local 变 nil，全站 HTTP 500 的根因）；
init 加 `runtime_ready()`，启动前用私有加载器 `--list` 验三个原厂
程序，失败写明原因拒绝启动，不再每 5 秒重拉一个 127。

0.1.0-29 在真机上验证通过：加载器 `--list` 三个程序 rc=0，控制器
跑起来了，LuCI 三页反复刷新正常。qemu 里的 `--list` 成功不能代替
真机那一项（qemu 看到的是宿主内核版本）。尚未验证：持续跑数分钟
以上、状态持续更新；实际组网发现节点；QCAWIFI 下 `wlan-sync` 写
`/etc/config/wireless` 是否生效。

## 这一批的落点

- 主树只进了两处：`zte-mesh.init` 的 `runtime_ready()`（apk 与 ipk
  共用，行为在新内核上不变），以及两份 Makefile 的 `PKG_RELEASE`
  28 → 29。
- 19.07 专用的东西全在 `legacy/19.07/`：重编后的运行包
  `zte-mesh-runtime-legacy.tar.gz`、Lua 页面、两处 `ns-run` 补丁、
  `tools/build-glibc-legacy.sh`（从源码重做这份运行包的脚本，CI
  不跑它——CI 直接用提交的这份已验证字节）。
- 新 workflow `.github/workflows/build-packages.yml`（手动触发）：
  apk 那份复用 `build-apk.yml`（给它加了 `workflow_call` 触发），
  ipk 那份用 OpenWrt 19.07.10 SDK（armvirt/64，19.07 没有 ipq807x
  target），构建时才把 legacy 覆盖层套到 checkout 上；构建后读包
  校验 glibc ABI tag 是 4.4.0、LuCI 是 Lua 页面、加载器 `--list`
  在 qemu 下能解析。
- 19.07 SDK 在构建机上的坑：exec 环境 umask 是 0007，须改 022；
  默认 mawk 缺 `asort`，feeds 索引会静默生成 0 行，须装 gawk；
  `/home` 是 overlayfs，make 须传 `CP="cp -fR"`；prereq 检查要
  Python 2，绕法是 `touch staging_dir/host/.prereq-build` 加
  `FORCE=1`。这几条都写进了 workflow 的注释里。
